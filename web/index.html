Cómo jugar
  1. Añadir instancia: elige Minecraft en la lista. Si quieres mods, elige Forge, NeoForge, Fabric, Quilt o LiteLoader y su versión en la segunda lista.
  2. Crear e iniciar. La primera vez WebPrism te pedirá un nombre offline y que aceptes el EULA.
  3. Para contenido, selecciona la instancia → Editar → Mods / Resource Packs / Shader Packs / Data Packs → Descargar….

Qué significa el estado web

  • Recomendado: 1.2.5, el objetivo probado de CheerpJ + LWJGL2.
  • Experimental: versiones antiguas/LWJGL2 hasta 1.12.2, incluidos loaders legacy. Pueden fallar.
  • Gestionar/exportar: versiones modernas (Java 17/21 + LWJGL3) o loaders modernos. Puedes crear la instancia e instalar contenido, pero el navegador aún no puede ejecutarlas.

Las instancias siguen el formato de Prism (instance.cfg, mmc-pack.json, patches/), así que puedes importarlas/exportarlas con una carpeta local.
